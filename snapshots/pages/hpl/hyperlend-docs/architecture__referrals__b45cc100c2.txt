# Referrals
You can generate your personal referral code directly within the HyperLend app by opening the "Referrals" pop-up.
Share your referral link to invite other traders to HyperLend. The code matches the username you have set on the dashboard page: `https://app.hyperlend.finance/?ref=CODE`
Referral details and invited users are visible within the referrals pop-up.
